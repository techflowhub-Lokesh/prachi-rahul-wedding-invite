# Prachi & Rahul — Wedding Invite

Digital scroll invitation for the wedding of **Rahul** and **Prachi**.

- **Date:** Wednesday, 2nd December 2026
- **Venue:** Sri Marwari Thakur Bari, Jorhat, Assam

Open `index.html` in a browser, or view it on GitHub Pages.

## Files
- `index.html` — page structure and text
- `style.css` — design (colours, fonts, layout)
- `script.js` — envelope opening, scratch-to-reveal date, petals, countdown, ceremony cards
- `assets/` — monogram, lotus and elephant artwork

To edit ceremonies, change the `EVENTS` list at the top of `script.js`.
